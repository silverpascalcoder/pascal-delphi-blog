# Modern Pascal

A clear, modern, Wirth‑inspired programming ecosystem built for developers who value correctness, simplicity, and long‑term maintainability.

Modern Pascal is a home for thoughtful programming — a place where clean language design, practical tooling, and decades of proven ideas meet today’s development realities. Whether you’re exploring FreePascal, writing modern systems code, or comparing language design across ecosystems like Odin, Zig, or Go, this site brings clarity to the conversation.

## What “Pascal” Means on This Site

Throughout this site, the term **Pascal** refers to the broader Pascal family of languages, including:

- Standard Pascal
- Object Pascal
- Delphi
- FreePascal
- Modern Pascal variants
- Wirth‑lineage descendants and compatible dialects

Unless otherwise stated, any reference to *Pascal* includes **Delphi** and all major modern implementations.

## Why Modern Pascal

Pascal has always been about clarity, structure, and intentional design. Modern Pascal continues that tradition by focusing on:

- Readable code that scales with complexity  
- Predictable performance without unnecessary abstraction  
- Tooling that respects the developer  
- A lineage of languages shaped by Wirth’s principles  
- Modern workflows using Git, Markdown, and fast static‑site tooling  

This site exists to show how Pascal still matters — not as nostalgia, but as a practical, modern choice.
